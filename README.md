# Answer Truck

AI receptionist and front-desk automation for HVAC and plumbing shops.

## Layout

| Folder | What lives here |
|--------|-----------------|
| `web/` | Marketing site for answertruck.com |
| `api/` | Receptionist backend: call handling, booking, call recording and transcripts |
| `docs/` | Business and technical notes, runbooks |

## Status

Early setup. Stack choices for `web/` and `api/` are still to be decided.
